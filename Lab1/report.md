# Lab 1 — Trajectory Drawing ("47") Report

The simulator run completed the full "47" trajectory successfully, tracing both digits with clean, sharp corners exactly as programmed in `trajectory_sim.qrs`. On the physical robot, `trajectory_real.qrs` executed without errors, but the available test area was too small for the robot to complete the full trajectory without running into space constraints, so a clean, direct comparison against the simulated path was not possible. Our hypothesis is that the timing values calibrated in the 2D simulator — which assumes idealized motion on an effectively unbounded canvas — correspond to a larger physical footprint than the room we had available, so the divergence observed is primarily a space/scale mismatch rather than a control or calibration failure. A secondary, harder-to-isolate factor is real-world friction and battery voltage variance, which the simulator does not model and which would cause the real robot's turn angles and travel distances to differ somewhat from the simulated ones even with adequate space. To properly compare simulation vs. reality, the next step would be to either scale down the trajectory (shorter Timer values) or test in a larger area, then measure the real robot's turn angles via encoder readings against the simulator's values.
